# Reproducibility status

This is a cleaned research-code release, **not a verified reproduction of the published scores**. The numerical tables and figures are not generated by this repository as shipped. Do not use the manuscript values as program output.

Changes made while aligning an older local implementation with the manuscript:

- The default `C4` pipeline uses all ten frames of the 2023 cardiac cycle, eight cascades, CP-Mamba, and MDSM.
- The motion map now averages **T cyclic differences** rather than `T-1` differences.
- Cardiac phase is estimated only from acquired undersampled ACS k-space, independently for each acceleration factor; the old phase script read full-reference k-space.
- At the three encoder sites, conditioned features are sent into the next downsampling stage as well as the skip connection. The old implementation conditioned the skip only.
- Training defaults use SSIM, AdamW with initial learning rate `1e-4`, and cosine decay to `1e-6`.

Validation not completed here: the current machine does not have `torch`, `fastmri`, or `mamba-ssm`, and the original full environment, data and checkpoints are not present in this release. Syntax and dependency-independent tests can be run, but an end-to-end forward pass, training run, and paper-number reproduction remain to be performed in a configured CUDA environment. In particular, code changes made to align with the manuscript must be trained/evaluated afresh; old checkpoints or old reported scores cannot be assumed to apply to this release.

Only the CMRxRecon2023 Cine loader is included. The CMRxRecon2025 Cine cross-center path and official test-set evaluation are not included yet.
